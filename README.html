Building and deploying ​

The site's build fetches live data from Bugzilla's API, which isn't reliably reachable from GitHub Actions. Because of that, the site is built and deployed locally instead of in CI:

yarn deploy

This builds the site and pushes .vitepress/dist to the gh-pages branch (via the gh-pages package), which GitHub Pages is configured to serve from directly - Settings > Pages > Source > "Deploy from a branch" > gh-pages. .vitepress/dist itself is never committed to main.
